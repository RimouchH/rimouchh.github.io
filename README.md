## Files
- index.html, about.html, research.html, teaching.html, awards.html, cv.html
- project-kitchen.html, project-misogyny.html, project-framing.html
- style.css
- CNAME (keeps rimchaif.com working — do not delete)

Upload the CONTENTS of this folder to your rimouchh.github.io repository (all .html files, style.css, CNAME, README.md, and the assets folder), commit, and the site updates at rimchaif.com within a minute or two. Keep the assets folder structure intact.
